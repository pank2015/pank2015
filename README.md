# Hi, I'm Pankaj 👋

**Solutions Architect** turning two decades of enterprise systems thinking toward one question:

> *How do you build agentic AI systems you can actually trust in production — grounded, cost-bounded, and human-governed?*

I'm on a deliberate journey from **Solutions Architect → Agentic AI Architect**, and I build in the open to prove it. Every project below applies real architectural discipline — ADRs, C4 models, provenance, human-in-the-loop, hard cost constraints — to autonomous AI.

---

### 🧭 What I'm about

- 🏗️ **Architecture-first AI.** Agents are systems, not prompts. I design them with the same rigor as any distributed system: explicit contracts, failure modes, guardrails, and a documented *why* behind every load-bearing decision.
- 🔒 **Trust as a feature.** Provenance-gating, grounding checks, prompt-injection defense, and "no claim without a source" — because autonomous output carries real reputational risk.
- 💸 **Constraint-driven design.** Several of my systems run at **$0/month** — repo-as-database, CI-as-compute, static-site-as-artifact, free-tier LLM fallback chains. Constraints make the engineering interesting.
- 🧑‍⚖️ **Human sovereignty.** My agents *propose*; a human merge is the only path to publication or behavior change. No silent drift.

`Python` · `React` · `TTS` · `Prompt-injection defense`
